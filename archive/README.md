# Archive

Superseded planning documents, kept for history rather than deleted -
both are real snapshots of how the project was reasoned about early on,
and several ROADMAP.md entries reference specific findings from them.

- **`NOTES.md`** (last substantive update 2026-08-21) — running notes from
  V0/early V1, written when only L'Oréal was loaded into the database, no
  ratio engine existed, and `tests/` was empty. Nearly everything in its
  "Open / Unfinished" list is long done (FX layer, ratio engine, GitHub
  remote, all 11 companies loaded, regression tests). Two items were
  still genuinely open and have been carried forward into
  `ROADMAP.md`'s "Explicitly deferred" section instead of staying buried
  here: the canonical concept layer, and dimensional/segment facts.

- **`TOMORROW.md`** (2026-08-21) — a single day's session plan (close the
  unmapped-concepts gap, rewrite the README, fix statement ordering).
  All of it shipped; the README block in particular was the seed of what
  `README.md` is today, several rewrites later.

**Do not treat either as a current task list.** For what's actually done
and what's actually next, see `ROADMAP.md` at the repo root - it has
fully superseded both of these.
